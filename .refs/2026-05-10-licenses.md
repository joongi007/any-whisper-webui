# 라이선스 정리

**Date:** 2026-05-10
**Context:** 사용자가 "라이선스가 안전한 오픈소스코드를 찾아서 레퍼런스로 활용"을 요구. 의존성 코드 라이선스와 **모델 가중치 라이선스**를 분리해서 봐야 한다. 특히 NLLB 모델은 CC-BY-NC (비상업).

### 모델 가중치 라이선스 (주의 필요)

| 모델 | 라이선스 | 사용 가능 여부 |
|---|---|---|
| Whisper (`tiny`~`large-v3`) | MIT | ✅ 자유 |
| Silero VAD 모델 | MIT | ✅ |
| pyannote/speaker-diarization-3.1 | **HuggingFace gated** — 사용자가 model card에서 약관 동의 + HF 토큰 필요 | ✅ 단, 사용자 토큰 필요. UI에서 안내. |
| pyannote/segmentation-3.0 | 동일 (gated) | 동일 |
| **NLLB-200** (`facebook/nllb-200-*`) | **CC-BY-NC 4.0 (비상업)** | ⚠️ **상업 사용 금지.** UI에 경고 라벨 표기. |
| UVR 모델들 (MDX-Net, Demucs 등) | 모델별 상이. Demucs는 MIT, MDX는 일부 비공개/연구용. | ⚠️ 안전한 모델만 화이트리스트 (예: Demucs htdemucs, UVR-MDX-NET-Voc-FT). 사용자 추가 다운로드는 본인 책임 표기. |

### DeepL
- API 약관 동의 필요. **무료 키는 비상업 한정** 조건이 있음 (DeepL 약관 참조).
- UI에서 키 입력 시 약관 링크 표시.

### YouTube (yt-dlp)
- yt-dlp 자체는 Unlicense.
- **YouTube ToS는 사용자가 직접 다운로드 권리를 가진 콘텐츠에만 적용**. 책임 고지를 README와 UI에 명시.

## Outcome

1. **NOTICE 파일** (`/NOTICE`) 작성: Apache-2.0 의존성 (Whisper-WebUI 참고, transformers, insanely-fast-whisper) 명시.
2. **LICENSE** (`/LICENSE`) 자체 프로젝트는 Apache-2.0로 채택 (가장 호환 범위 넓음, 특허 보호 포함).
3. **UI 라벨링:**
   - NLLB 선택 시 "비상업 라이선스 (CC-BY-NC)" 배지 표시.
   - DeepL 선택 시 "API 키 약관 본인 확인" 안내.
   - YouTube URL 입력 시 "다운로드 권리 본인 확인" 안내.
   - pyannote 활성화 시 "HF 약관 동의 + 토큰 입력" 안내 모달.
4. **UVR 모델 화이트리스트:** htdemucs (Demucs v4, MIT) + UVR-MDX-NET-Voc-FT (확인 후 추가). 그 외는 사용자가 직접 모델 파일 배치 시 본인 책임.
