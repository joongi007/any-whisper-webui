# Iter 2 — 탭으로 소스 분리

## 이전 비판 → 적용
- (1) 소스 라디오 → **탭**으로 변경. 각 탭은 자기만의 입력 위젯과 단축 옵션을 가짐.
- (3) 결과 영역에 **잡 진행** 상태도 표시.

## 와이어프레임 (2단 그리드)
```
┌─────────────────────────────────────────────────────────────────────┐
│ any-whisper-webui                                  [☾] [⚙]          │
├─────────────────────────────────────────────────────────────────────┤
│ ┌────────────────────────────────────┐ ┌──────────────────────────┐ │
│ │ [File] [YouTube] [Mic] [Tab Audio] │ │ Pipeline Options         │ │
│ │ ─────────────────────────────────  │ │ ─────────────────────────│ │
```

## 변화의 핵심
- 좌측 메인이 **소스 입력**, 우측 사이드가 **공통 옵션**.
- 입력 위젯은 탭별로 독자적: 파일=드롭존, YouTube=URL+썸네일 미리보기, Mic=장치 선택+레벨미터, Tab=공유 시작 버튼+안내문.
- "Pre / Post"는 디스클로저 화살표(▸)로 접힘. 기본 펼침 = OFF.

## 새로 떠오른 비판
1. **여전히 옵션이 많다.** 우측 패널이 길어지면서 모바일·작은 창에서 숨을 곳이 없다.
2. **잡 흐름이 보이지 않는다.** "Run"을 눌러도 어떤 단계(VAD→Whisper→Diarize→Translate)를 거치는지 시각적으로 표현 X.
3. **"여러 파일"** 시나리오 부재. 파일 4개 선택 시 어떻게 될지 미정.
4. **실시간(Mic / Tab Audio) 탭**이 같은 [Run] 버튼을 공유하는데, 실시간은 정작 "Run"이 아니라 "Connect / Disconnect" 토글이어야 한다.

→ 다음 회차에서 (2)를 stepper로 풀고, (4) 실시간을 분리한다.
