# Iter 4 — Job-centric

## 이전 비판 → 적용
- (1) **다잡 동시성**: 시작 후 즉시 새 잡을 만들 수 있다. 진행 중 잡들은 우측 슬라이드 "Jobs" 패널에 카드로 누적.
- (4) **History 페이지** 분리.

- 좌 사이드바: 5개 메뉴.
- 우 슬라이드 패널: 활성 잡 카드. 클릭 → 잡 상세 페이지.
- 메인은 현재 페이지(File 탭 등)에 집중.

## 잡 카드 사양
```
┌─────────────────────────────────────┐
│ ▶ my-talk.mp3 · file                │  ← title · source
│ Whisper · large-v3-turbo            │  ← summary
│ ●━━━●━━○━━○━━○━━○━━○                │  ← stepper dots
│ Stage: Whisper · 42% · ETA 2:18    │
│ [⏸ Pause] [✕ Cancel] [→ Open]      │  ← 호버 시 노출
└─────────────────────────────────────┘
```
완료 잡:
```
┌─────────────────────────────────────┐
│ ✓ my-talk.mp3 · 02:34 elapsed       │
│ Whisper · large-v3-turbo            │
│ [⬇ SRT] [⬇ VTT] [⬇ TXT] [→ Open]    │
└─────────────────────────────────────┘
```
실패 잡:
```
┌─────────────────────────────────────┐
│ ✕ song1.mp3 · OOM at UVR            │
│ [↻ Retry with smaller model]        │
└─────────────────────────────────────┘
```

## 잡 상세 페이지 (`/jobs/:id`)
- 상단: 잡 메타(이름, 시작/종료, 옵션 요약).
- 중단: stepper(가로 큰 사이즈) + 단계별 로그.
- 하단: TranscriptViewer + Export 버튼들.

## 새로 떠오른 비판
1. **실시간(Mic/Tab) 페이지가 잡 모델에 잘 안 맞는다.** 끝이 없고 export는 "지금까지"로 잘라야 함.
2. 잡 카드의 정보 밀도가 적당한가? **모바일에서 사이드바+잡 패널을 동시에 띄울 공간이 없다.**
3. 잡 패널이 항상 떠 있으면 **콘텐츠 영역이 좁아진다**. 토글 + 자동 숨김 정책 필요.
4. **사용자가 잡 시작 후 "어디로 가야 하지"** 가 모호 — 잡 패널의 카드를 클릭해 상세로 가는 흐름이 자연스럽긴 하나, "Open" 버튼을 더 명시적으로.

→ 5회차에서 실시간 페이지 분리, 6회차에서 정보 밀도/모바일.
