# Iter 3 — Pipeline Stepper

## 이전 비판 → 적용
- (2) **Pipeline stepper** 도입. 사용자가 거치게 될 모든 단계가 한눈에. 비활성 단계는 흐림.
- 스텝퍼는 입력과 출력 사이의 "처리" 메타포로 작동.

## 변화의 핵심
- 우측 사이드가 **계획서(plan)** 가 됨: 어떤 단계가 실행될지 미리 보여줌. 클릭하면 해당 단계의 옵션이 모달/슬라이드로 열림.
- 결과 영역 상단에 가로 progress dot 7개. 진행 단계마다 채워짐.
- 자막은 라이브로 추가됨 (WS partial/final 활용).

## 새로 떠오른 비판
1. **여전히 1잡 중심.** 두 개를 동시에 돌리면 화면이 어디로 가는지 미정.
2. **Mic/Tab Audio 탭은 Stepper가 어색하다** — 실시간은 "스트림"이지 "잡"이 아님. 단계가 다르고 끝이 없음.
3. 우측 사이드의 "단계 클릭 → 옵션 모달"은 좋지만, **사용자가 이걸 클릭 가능하다는 어포던스(affordance)** 가 약함. 호버 색 변화/연필 아이콘 같은 신호 필요.
4. **잡이 끝난 후의 화면**도 라이브 결과와 같은 곳을 쓰고 있음 → 히스토리 페이지 별도 필요.

→ 4회차에서 (1)(4)를 잡 중심 카드 모델로 풀고, (2)는 5회차에서 실시간 페이지를 분리.
